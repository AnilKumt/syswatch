# Contributing to syswatch

Thank you for your interest in contributing to `syswatch`!

---

<details>
<summary><b>Development Workflow & Pull Requests</b></summary>

1. **Fork & Branch**: Create a feature branch off `main` (e.g., `feature/custom-alerts` or `fix/disk-path-error`).
2. **Code Standards**: Maintain type hints and standard docstrings.
3. **Linting**: Ensure `ruff check src tests` passes with zero warnings.
4. **Tests**: Add unit tests for new features. All tests must pass via `pytest`.
5. **Pull Request**: Submit a PR to `main` with a description of changes and test results.

</details>
